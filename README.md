# Ovale

Jeu de rugby à XV et à VII, dans le navigateur : contre l'ordinateur, ou à deux sur le même Wi-Fi (connexion directe entre les appareils).

Jouer : https://smer96.github.io/ovale/

Sur téléphone, le jeu s'installe comme une appli : bouton « Installer l'appli » sur Android, ou Partager puis « Sur l'écran d'accueil » sur iPhone.
